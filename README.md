The App, Autowork, is a local application the runs fully on the users laptop. The concept is to streamline documentation for providers who input data into Wida. Without Autowork, the provider would have to manually type into Excel the values generated. Autowork works in the background and does it automatically.                                     
The Autowork app does not send data to the cloud. All data stays on the users local device. The app is therefore fully HIPPA compliant.                                                                          
To use Autowork, simply click the link to download. For best results move the app to the desktop. Next run the App. Doing so will automaticly export the extension in a folder "Autowork Extension". Then go to chrome://extensions, ensure developer mode is toggled on. Click 'load unpacked' and select 'Autowork Extension'. You are all set.                 
Autowork 3.0.0 currently works for the "WIDA MODEL Score Calculator" @https://wida.wisc.edu/assess/model/calculator, and the "WIDA Screener for Kindergarten Score Calculator"  @https://wida.wisc.edu/assess/screener/kindergarten/calculator. A popup "Autowork recording in progress" indicates that data is being saved to the local Autowork App.
